# React Routing

A Vite-powered React project configured with:

- React Router
- Tailwind CSS
- Bootstrap

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Environment variables

Vite loads variables from `.env` automatically. Client-side variables must use
the `VITE_` prefix:

```env
VITE_APP_NAME=React Routing
```

Copy `.env.example` when creating environment files for other machines. The
local `.env` file is ignored by Git.
